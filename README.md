# Leisure Suit Larry in the Land of the Lounge Lizards - PC source code

Original source and resources for Sierra On-Line's 1987 AGI game, by Al Lowe.

Imported from [historicalsource/leisure-suit-larry-1](https://github.com/historicalsource/leisure-suit-larry-1)
at commit [`fb619fd`](https://github.com/historicalsource/leisure-suit-larry-1/commit/fb619fd0af37c3f846c162f5ae1185e4b0e1e729),
with its Git history preserved. All files except this README are unchanged from
upstream.

- [SRC](SRC): original AGI logic scripts (`.CG`), messages (`.MSG`), definitions, and vocabulary.
- [PIC](PIC), [VIEW](VIEW), and [SND](SND): picture, animation, and sound resources.
- [Audio](Audio): music files and audio tools, including C and assembly source in [Audio/SOURCE](Audio/SOURCE).
- [Fastback Backup 19900123](Fastback%20Backup%2019900123): the backup image included upstream.

This is a fuller archive than the earlier
[scripts-and-definitions collection](https://github.com/historicalsource/leisuresuitlarry).
The game scripts use Sierra's AGI language, despite the C-like syntax and `.H`
filenames. The AGI interpreter source and a complete build toolchain are not
included, so this is not a self-contained game build. Rebuilding has not been
verified. Original notices are retained; no new license is assigned to the
archived material.
